# What is this folder?

This folder consists of markdown files that explain some (mostly) unexplained
questions in this course.

## Why?

One thing I've learned from my programming journey is that, tutorials do NOT
work. They only give what the documentation gives in video format. This is what
kills your ambition, or excitement, to programming.

In these markdowns, I'll try to explain the topics on top of the documentation
itself. So, yes. You do need to read documentation to learn anything in a
programming language.

## Why? v2.0

Documentations give you the most up-to-date and correct information. There is
no better way to learn a language other than the documentations.
